# Computational Environment

## Public reproduction

The public workflow uses R and Python.

Python packages used by the public scripts include:

- numpy
- pandas
- matplotlib
- scipy
- geopandas
- shapely

R packages used by the public scripts include:

- data.table
- ggplot2
- ggprism
- patchwork
- cowplot
- scales

The complete public workflow has been verified in Code Ocean using R 4.5.1 and
the capsule's system Python 3 interpreter. Local development and validation were
also performed with R 4.4.0 and Python 3.13.

No GPU or other non-standard hardware is required.
