# Reproducing the GitHub package

Follow [Run locally in the main README](README.md#run-locally) from the repository root. Local outputs are written to `output/`; dependencies and Rscript configuration are described in [ENVIRONMENT.md](ENVIRONMENT.md).

The included `data/non-confidential/` inputs reproduce the displayed figures and tables. The additional county dataset download is explained in [data/README.md](data/README.md). Regression estimation scripts and their underlying input requirements are documented in [code/regression/README.md](code/regression/README.md).

Instructions for building and running the companion Code Ocean capsule are in [environment/README.md](environment/README.md).
